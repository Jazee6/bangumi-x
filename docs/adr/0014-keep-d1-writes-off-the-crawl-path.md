# Keep D1 writes off the crawl path

上线后爬虫沿内链抓取长尾实体，每次直接访问都向公开实体目录插入新行，公开条目页还会把放送快照写入 D1，日写入行数超过 Free Tier 的 10 万上限且随站点地图扩大持续增长。为把日写入控制在 3 万行以内，修订 ADR 0005 的目录边界：直接访问只计入真实访客，爬虫抓取不新增目录行；章节不进入目录与站点地图；不可索引的实体只在需要撤出站点地图时更新已有行，不再新增；重新验证由请求驱动维护负责，请求路径只在可索引判定变化时写入。目录以 `(resource_type, external_id)` 作为 `WITHOUT ROWID` 主键，作为 ADR 0003 UUIDv7 主键的例外，并只保留按类型、状态与验证时间的二级索引，使每次插入从 5 棵 B-tree 降到 2 棵。放送快照只为存在进度的条目持久化，公开条目页仅依赖 ADR 0010 的边缘缓存。

## Consequences

- 重建目录时只迁移种子来源（每日放送、本年度热门、排行榜、关联、公开收藏列表）的可索引与待验证行，约 7 千行；爬虫时期以直接访问进入的约 4.8 万个可索引条目、角色与人物，以及全部章节与不可索引行被丢弃。站点地图中的条目约从 2.5 万降到 7 千，角色与人物几乎清空；已被搜索引擎收录的页面不会因此被移除，后续由真实访客与种子来源重新扩展。
- 爬虫由 Server 按 User-Agent 识别：Web SSR 转发访客的 User-Agent，直接请求按自身 User-Agent 判断，缺失视同爬虫。误判只会少记录，不会污染目录；记录只发生在 Server 边缘缓存未命中时，真实访客带来的增长会较慢。
- 存量放送快照按小批量分摊到每小时维护中清理，避免一次性删除耗尽当日写入额度。
