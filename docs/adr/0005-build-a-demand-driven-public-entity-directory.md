# Build a demand-driven public entity directory

Bangumi X 不枚举并镜像 Bangumi 的全部实体，而把每日放送、本年度热门、历年排行榜和站内访问发现的非 NSFW 条目、角色与人物纳入需求驱动目录，以此生成稳定、可分片的站点地图并扩展公开内链。目录只持久化实体 ID、类型、发现来源、首次与最后验证时间、可索引状态和必要关系；标题、简介、封面等资料仍按需从上游读取并缓存。该边界优先覆盖与“放送与发现”相关的真实需求，并控制 Cloudflare Free Tier 下的抓取、存储与刷新成本，代价是长尾实体只有被发现后才进入本站的公开目录。
