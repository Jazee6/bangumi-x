# Pair Mini and Web users outside web-view

Personal-subject WeChat Mini Programs cannot rely on `web-view`, so an authenticated Bangumi X user issues a ten-minute, single-claim QR and short-code credential in the Web account menu; the Mini claims it and remains the only place that can confirm the irreversible merge. The Web user always survives and receives the WeChat login identity and personal data, while preview versioning, one-to-one WeChat identity enforcement, and a separate recovery token protect confirmation and session handoff.
