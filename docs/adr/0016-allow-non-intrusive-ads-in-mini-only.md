# Allow non-intrusive ads in Mini only

Bangumi X 的 Mini 端允许展示微信流量主 Banner 广告，用于覆盖运营成本；Web 端、付费功能与其他商业化方案仍遵循 ADR 0009，保持无广告、无付费。广告只出现在内容浏览页的页尾，不使用插屏、激励视频或开屏，也不进入首屏、功能页或任何会打断操作的位置。

Mini 广告由微信官方广告组件提供，不引入第三方 SDK，也不向广告方传递 Bangumi 数据或站内用户信息；广告位 ID 为 Mini 代码中的单一常量，留空即关闭，加载失败时整块折叠。Web 的关于、服务条款与隐私说明改为「Web 无广告，Mini 展示微信流量主广告」，Mini 关于页同步说明广告来源、范围与用途。

仍需维护者在上线前确认 Bangumi 数据、封面、标识及开发者协议允许此类展示；若上游条款不允许，应撤下 Mini 广告而不是扩大解释。
