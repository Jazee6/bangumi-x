# Cache current public collection lists for five minutes

公开收藏列表的稳定链接继续表示列表当前内容而非发布快照，但 Server 与 Web 允许匿名公开响应缓存 5 分钟。列表内容、名称或公开状态发生变化后，私有管理接口仍立即反映写入结果，公开链接及搜索引擎可在最多 5 分钟内继续看到先前缓存版本；撤回公开状态也接受同样的传播延迟，并在隐私政策中明确披露。该选择用有限的一致性窗口换取更少的 D1 与 SSR 读取、更快的匿名访问和更低的 Free Tier 资源消耗；私有收藏库、收藏列表管理和进度接口仍为 `private, no-store`，不采用这一策略。
